# Source Handling

Choose the lightest inspection path that gives a trustworthy read.

## Articles and websites

- Prefer the original article or docs page.
- Look for what the thing actually does, not just promotional framing.

## GitHub repos

- Check the README, tags, recent activity, and whether the repo looks maintained.
- Name clearly if the value is a reusable pattern rather than code.

## Screenshots and images

- Describe what is visible before inferring.
- If the screenshot is ambiguous, say what cannot be verified from the image alone.

## Videos

- Prefer title, description, chapters, transcript, and supporting links over vibes.
- Summarize the claim before evaluating usefulness.

## Social posts

- Separate the actual idea from the performative framing around it.
- If the post links to a deeper source, inspect that source.
