# Storage

Choose the smallest durable place that matches the audience.

## Public artifacts

- repo `docs/public/` or `docs/updates/`
- a dedicated `posts/` folder when the repo already uses one

## Internal artifacts

- `notes/` or `docs/notes/`
- GitHub issue summary if the issue is canonical

## Rule of thumb

If the artifact should be shareable outside the repo, use a public folder.
If it is only for internal continuity, keep it near the issue or notes.
