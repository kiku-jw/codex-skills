# Artifact Types

Pick the smallest artifact that matches the goal.

## Build diary

Use when:

- work just finished
- the useful part is decisions and trade-offs

Structure:

- what changed
- why it changed
- what we learned
- what is next

## Release notes

Use when:

- shipping changes to users
- you need a short, scannable list

Structure:

- added
- improved
- fixed
- known issues

## Launch post

Use when:

- the product is new or repositioned
- the audience is external

Structure:

- problem
- why now
- what it does
- proof or demo
- how to try

## Case study

Use when:

- there is a clear before/after
- outcomes are credible

Structure:

- context
- constraints
- solution
- results
- lessons

## Demo script

Use when:

- you need a short narrative for a screen share

Structure:

- setup
- key steps
- payoff
