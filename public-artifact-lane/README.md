# public-artifact-lane

Codex skill for turning real work into public-ready artifacts with evidence-first framing.

## What it does

- chooses the right artifact type for the moment
- drafts build diaries, release notes, launch posts, case studies, or demo scripts
- keeps the first screen useful and concrete
- avoids inventing results or leaking private details

## Repository layout

- `SKILL.md` - main skill instructions
- `agents/openai.yaml` - UI metadata for skill surfaces
- `references/artifact-types.md` - artifact selection guide

## Example prompts

- `write a build diary from this work`
- `make release notes`
- `turn this into a public post`
- `prepare a launch writeup`
