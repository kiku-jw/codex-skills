# Transcribe Skill

Canonical parent entry point for the transcription skill family.

## Included Skills

- Root skill: `transcribe`
- Companion skill: [`transcribe-basic`](../transcribe-basic/)
- Companion skill: [`transcribe-diarize`](../transcribe-diarize/)

The parent skill routes work into the smallest honest transcription lane.
Companion skills use this directory's shared script and API reference, so install
the whole family.
