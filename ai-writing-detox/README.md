# ai-writing-detox

Codex skill for removing obvious AI-writing tics from public-facing drafts without flattening the author's real voice.

## What it does

- cuts empty hype, throat-clearing, and fake authority
- smooths out artificial LLM rhythm
- keeps meaning while making the text sound calmer and more human
- works well for posts, README copy, public notes, and build diaries

## Repository layout

- `SKILL.md` - main skill instructions
- `agents/openai.yaml` - UI metadata for skill surfaces
- `references/patterns.md` - common signatures to remove

## Example prompts

- `make this sound less AI`
- `detox this draft`
- `polish this post before publishing`
- `clean up this README copy`
