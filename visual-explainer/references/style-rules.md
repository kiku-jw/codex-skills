# Style Rules

The artifact should look intentionally designed, not default.

## Typography

- Pick a clear heading font and a readable body or mono companion.
- Avoid Inter, Arial, Roboto, and default system stacks as the primary identity.

## Color

- Use CSS variables.
- Define at least:
  - `--bg`
  - `--surface`
  - `--border`
  - `--text`
  - `--muted`
  - 2-4 accent colors

## Layout

- Use one clear hierarchy.
- Keep important content on the first screen.
- Use spacing generously enough that dense data still scans cleanly.

## Accessibility

- Keep contrast readable.
- Do not rely on color alone for status.
- Use semantic table markup for tables.
- Respect reduced motion if animation is added.

## Anti-patterns

- flat generic dashboards
- over-animated decorative nonsense
- giant paragraphs inside tiny cards
- dark themes with weak contrast
